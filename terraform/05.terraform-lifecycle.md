# Terraform Lifecycle

1. Terraform init
2. Terraform plan
3. Terraform apply

----

1. main.tr'i yazdık sonrasında terraform init'i kullanacağız 
2. initialization successful olduktan sonra terraform plan'i çalıştırıyoruz 
plan will tell you what's going to happen. Dry run
3. terraform apply will apply the configuration and will start creating the resources
